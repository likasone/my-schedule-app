# Release v1.0.0

[English](./v1.0.0.en.md) | 简体中文

## 版本要点
- **全新日程、计划与便签体系**：支持随手记事、日程看板、多端同步以及基于艾宾浩斯遗忘曲线的智能复习计划。
- **全方位硬件级隐私保护**：
  - 指纹/面容生物识别安全锁下沉至设置首页独立卡片管理；
  - Android 移动端底层引入物理级防窥机制（`FLAG_SECURE`），彻底屏蔽多任务切换栏缩略图泄密，杜绝应用外偷窥；
  - 切出应用即刻触发高严密会话重锁，解锁唤醒强制生物鉴权。
- **关于中心纯净化与专属更新**：
  - 剔除冗余外部链接与打赏模块，全面对齐本仓库的专属发行与在线更新通道；
  - 正式发布采用长效永久密钥签名，保障跨版本更新数据 100% 完整继承。

## 新增与改进
### 1. 安全与隐私架构
- **指纹锁设置化**：指纹开启与关闭开关移至设置主页，自适应深浅色模式与液态玻璃材质，支持硬件能力动态检测。
- **多任务防窥遮罩**：安卓退入后台（`onPause`）自动激活安全窗口标志，多任务切换器中卡片呈现纯色防窥背景，返回前台自动恢复，截屏与导图不受影响。
- **安全备份防护**：禁用系统明文自动云备份（`allowBackup="false"`），确保本地数据库沙箱独立安全。

### 2. 日程与计划管理
- **艾宾浩斯复习算法**：支持自定义科学间隔复习规划，级联关联日历与待办任务。
- **便签全宽搜索与自适应**：便签列表支持全宽无遮挡搜索，软键盘弹起智能避让。

### 3. 系统精简与优化
- 优化包体大小，移除无用依赖与孤儿代码；
- 建立专属端到端自动发布与版本校验机制。
