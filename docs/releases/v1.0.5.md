# Release v1.0.5

[English](./v1.0.5.en.md) | 简体中文

## 版本要点
- **保存失败的报错现在会直接给出诊断**：不用再猜是权限、占用还是磁盘问题。
- 本版以可观测性为主，不改动数据格式，升级不影响已有日记与设置。

## 新增与改进
### 1. 写库失败现场诊断
- 保存日记失败时，报错信息里会附带以下内容，便于直接定位：
  - 应用可执行文件路径；
  - 应用实际使用的数据目录绝对路径；
  - 从**应用进程内部**对该目录做一次写探测的结果（能否创建文件）；
  - 数据库文件的大小与最后一次成功写入时间。
- 该诊断不依赖日志文件，因此在无法写入的机器上同样能看到——这正是排查"写库一直失败"时最需要的信息。

### 2. 版本号可区分
- 版本号递增为 `1.0.5+105`，便于确认当前运行的是哪一次构建。

## 修复
- 汇总自 v1.0.0 以来已修复的问题：
  - 发布门禁：测试失败不再被 `|| true` 吞掉，生成代码检查不再自动提交推送；
  - 标签颜色被写成全透明（颜色值为 0）导致 `#`、选中描边与部分文字不可见；
  - 上锁日记本的验证绕过统一身份验证入口，改为经 `IdentityVerifier` 验证；
  - 首次同步后因 `lastSyncAt` 不推进导致自动同步被永久阻断；
  - 恢复被自动提交误删的 Drift 生成文件 `app_database.g.dart`。
